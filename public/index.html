Ground

Evidence receipts for agent claims. Give Ground a URL: every non-null value comes back with the verbatim span that proves it — checked by code against the text that was actually fetched, not asserted by a model — plus the sha256 of that text and when it was read. Anyone can re-fetch the page and re-hash the receipt in one second.

What it will not do

  • It will not guess. A field the page does not state comes back null with a reason.
  • It will not soften a miss. A value it cannot prove with a verbatim span is withheld, not paraphrased.
  • It will not hide a failure. An unreachable page is reported as unreachable, not as an empty result.
The model is only a reader. It locates a span; code decides whether that span is really on the page. Nothing that fails that check is ever returned. catalog.json
